# 工学実験2 第3回課題

日本語対応の LuaLaTeX を使用します。

1. このフォルダを VS Code で開きます。
2. `main.tex` に実験内容を記入して保存すると、自動でビルドされます。
3. コマンドパレットから `LaTeX Workshop: View LaTeX PDF file` を選ぶと PDF を表示できます。

PDF は `build/main.pdf` に生成されます。画像は `figures/` に入れてください。
手動でビルドする場合は、このフォルダで `latexmk main.tex` を実行してください。
